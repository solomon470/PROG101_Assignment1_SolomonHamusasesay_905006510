# Project Overview

## Project Title
School Attendance Management System (SAMS)

## Background
Schools need to keep accurate records of student attendance. When attendance is recorded manually, it can take time to find information and prepare reports. This project proposes a simple system to make attendance management easier.

## Problem Statement
Manual attendance recording can lead to misplaced records, slow searching and difficulties when preparing attendance summaries.

## Aim
To design a system that helps schools register students, record attendance and check attendance information.

## Objectives
1. To register student details.
2. To record students as present or absent.
3. To search for student attendance records.
4. To prepare simple attendance reports.

## Expected Users
The system is intended for authorised school staff responsible for recording and checking student attendance.
