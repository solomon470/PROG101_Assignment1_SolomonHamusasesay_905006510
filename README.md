# School Attendance Management System (SAMS)
## Introduction
  The School Attendance Management System (SAMS) is a proposed system designed to help schools manage student attendance. 
  It allows authorised users to register   students, record attendance, search for student records and generate attendance reports.
  The project demonstrates the use of programming logic, algorithms and pseudocode to solve a real-life problem in schools.

  ## Project Objectives
The main objectives of SAMS are:
 1. To register new students and store their details.
 2. To record students' daily attendance.
 3. To identify students who are present or absent.
 4. To search for student attendance records.
 5. To generate attendance reports.

  ## Main Features
    - Student registration
    - Attendance recording
    - Student record searching
    - Attendance report generation
    - Validation of student information
