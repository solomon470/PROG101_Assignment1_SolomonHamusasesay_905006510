## 1. Input
  Input refers to the information entered into a computer system by the user.
  In the School Attendance Management System, the input includes the student's ID, full name, class, attendance date and attendance status. 
  The teacher or administrator enters these details into the system so that student information and attendance can be recorded correctly.
  
## 2. Processing
  Processing refers to the operations performed by the computer on the information entered by the user.
  In the School Attendance Management System, processing includes checking student details, verifying student IDs, recording attendance, searching for student records and calculating the attendance percentage.
  These operations help the system manage student attendance accurately.
  
  ## 3. Output
Output refers to the information produced by the computer after processing the data.
In the School Attendance Management System, the output includes student details, registration confirmation messages, attendance records and attendance reports.
The system also displays the number of days a student was present or absent and the attendance percentage.

## 4. Variables and Constants
Variables are used to store information that can change while the system is running. Examples include StudentID, StudentName, StudentClass, AttendanceStatus, PresentDays and AbsentDays.
Constants are values that remain the same throughout the program. Examples include SYSTEM_NAME, PRESENT and ABSENT.
They help the system use fixed information consistently.

## 5. Data Types
Data types are used to identify the type of information stored in the system.
SAMS uses different data types to store student information and attendance records.
- String: Used to store student names and classes.
- Integer: Used to store student IDs and the number of days present or absent.
- Boolean: Used to represent true or false conditions.
- Float: Used to store attendance percentages.
- Date: Used to store the date attendance is recorded.

  ## 6. Decision Structures
Decision structures allow the system to make decisions based on certain conditions.
SAMS uses IF, ELSE IF and ELSE statements to check information and decide what action to take.
For example, if a student ID exists, the system allows attendance to be recorded. If the student ID does not exist, the system displays an error message. It also checks whether the attendance status is Present or Absent before saving the record.

## 7. Boolean Logic
Boolean logic is used to check conditions that can only have two possible results: TRUE or FALSE. In SAMS, Boolean logic helps the system determine whether a student is registered, whether the entered details are complete and whether an attendance status is valid.
For example, if a student is registered, the condition is TRUE. If the student is not registered, the condition is FALSE.

## 8. Repetition Structures
Repetition structures allow the system to perform the same instructions more than once. SAMS uses repetition to display the main menu repeatedly until the user chooses the Exit option.
For example, after registering a student or recording attendance, the system returns to the main menu so the user can select another operation. This makes the system easier to use.
